## ICFindExchangeHandler interface

Observes completed C-FIND exchanges on the SCU side. Invoked for each C-FIND-RSP received from the remote SCP, allowing the implementer to process query results (matching datasets) or inspect the final status of the query operation.

```csharp
public interface ICFindExchangeHandler : 
    INotificationHandler<StreamExchangeNotification<CFindRequest, CFindResponse>>
```

### Remarks

C-FIND performs information-model queries (Patient Root, Study Root, etc.). The SCP may return multiple pending responses, each containing a matching dataset, followed by a final success/failure status. See DICOM PS 3.7 §9.1.2.

## INDeleteExchangeHandler interface

Observes completed N-DELETE exchanges on the SCU side. Invoked after the remote SCP returns an N-DELETE-RSP, allowing the implementer to confirm that the managed SOP instance was deleted and inspect the response status.

```csharp
public interface INDeleteExchangeHandler : 
    INotificationHandler<UnaryExchangeNotification<NDeleteRequest, NDeleteResponse>>
```

### Remarks

N-DELETE requests the SCP to remove an existing managed SOP instance (e.g. a completed print job or film session). The response contains only a status — no dataset is returned. See DICOM PS 3.7 §10.1.6.

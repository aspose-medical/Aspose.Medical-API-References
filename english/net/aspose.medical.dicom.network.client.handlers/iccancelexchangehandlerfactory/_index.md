## ICCancelExchangeHandlerFactory interface

A factory that creates handlers that observe C-CANCEL exchanges on the SCU side. Invoked after a C-CANCEL-RQ is sent to the remote SCP, allowing the implementer to log or audit the cancellation attempt. Because C-CANCEL has no corresponding response from the SCP, the response slot carries [`NoneDicomNetworkResponse`](../../aspose.medical.dicom.network.messages/nonedicomnetworkresponse).

```csharp
public interface ICCancelExchangeHandlerFactory : 
    INotificationHandlerFactory<UnaryExchangeNotification<CCancelRequest, NoneDicomNetworkResponse>>
```

### Remarks

C-CANCEL asks the SCP to stop a pending C-FIND, C-GET, or C-MOVE operation. The SCP does not send a dedicated C-CANCEL response; instead, it terminates the pending operation and returns a final status on the original service's response stream. See DICOM PS 3.7 §9.3.2.3.

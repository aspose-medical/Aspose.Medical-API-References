## INSetExchangeHandler interface

Observes completed N-SET exchanges on the SCU side. Invoked after the remote SCP returns an N-SET-RSP, allowing the implementer to confirm which attribute values were successfully modified on the managed SOP instance and inspect the response status.

```csharp
public interface INSetExchangeHandler : 
    INotificationHandler<UnaryExchangeNotification<NSetRequest, NSetResponse>>
```

### Remarks

N-SET modifies one or more attribute values on a managed SOP instance (e.g. updating film box layout, UPS work item parameters, or annotation content). The response dataset may echo the modified values. See DICOM PS 3.7 §10.1.3.

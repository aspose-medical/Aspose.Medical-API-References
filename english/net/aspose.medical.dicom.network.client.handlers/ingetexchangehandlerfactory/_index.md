## INGetExchangeHandlerFactory interface

A factory that creates handlers that observe N-GET exchanges on the SCU side. Invoked after the remote SCP returns an N-GET-RSP, allowing the implementer to read the requested attribute values from the managed SOP instance and inspect the response status.

```csharp
public interface INGetExchangeHandlerFactory : 
    INotificationHandlerFactory<UnaryExchangeNotification<NGetRequest, NGetResponse>>
```

### Remarks

N-GET retrieves one or more attribute values from a managed SOP instance (e.g. printer status, film box parameters, or UPS work item state). The response dataset contains the requested attributes. See DICOM PS 3.7 §10.1.2.

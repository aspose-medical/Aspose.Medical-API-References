## INEventReportExchangeHandlerFactory interface

A factory that creates handlers that observe N-EVENT-REPORT exchanges on the SCU side. Invoked after the remote SCP returns an N-EVENT-REPORT-RSP, allowing the implementer to process event information (event type ID, event data) and inspect the response status.

```csharp
public interface INEventReportExchangeHandlerFactory : 
    INotificationHandlerFactory<UnaryExchangeNotification<NEventReportRequest, NEventReportResponse>>
```

### Remarks

N-EVENT-REPORT is an asynchronous notification sent by the SCP to inform the SCU about an event that occurred on a managed SOP instance (e.g. storage commitment result, UPS state change, printer status change). See DICOM PS 3.7 §10.1.1.

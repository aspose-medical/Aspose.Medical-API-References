## INActionExchangeHandlerFactory interface

A factory that creates handlers that observe N-ACTION exchanges on the SCU side. Invoked after the remote SCP returns an N-ACTION-RSP, allowing the implementer to examine the action outcome, optional action-reply data, and the response status.

```csharp
public interface INActionExchangeHandlerFactory : 
    INotificationHandlerFactory<UnaryExchangeNotification<NActionRequest, NActionResponse>>
```

### Remarks

N-ACTION requests an SOP instance to perform a specific action (e.g. print, media creation, storage commitment). The response may include action-reply information describing the result. See DICOM PS 3.7 §10.1.4.

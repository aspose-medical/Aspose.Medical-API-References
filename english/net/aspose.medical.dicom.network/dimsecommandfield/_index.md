## DimseCommandField enumeration

Specifies the DICOM network services as defined by the DICOM upper-layer protocol. Each value corresponds to a unique command field used in DICOM message communication between Application Entities over a network. In addition, services are split into request/response (when applicable).

```csharp
public enum DimseCommandField : ushort
```

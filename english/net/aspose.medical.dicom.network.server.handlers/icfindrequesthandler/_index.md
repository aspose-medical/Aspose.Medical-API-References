## ICFindRequestHandler interface

Handles inbound C-FIND requests on the SCP side. Use this handler to match an Identifier against managed instances and return zero or more pending matches followed by a final status. See [ DICOM PS3.7 §9.1.2 (C-FIND Service)](https://dicom.nema.org/medical/dicom/current/output/chtml/part07/chapter_9.html) and [ §9.3.2 (C-FIND-RQ / C-FIND-RSP / C-CANCEL-FIND-RQ) ](https://dicom.nema.org/medical/dicom/current/output/chtml/part07/sect_9.3.2.html).

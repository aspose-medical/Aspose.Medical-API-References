## DicomNetworkConnectionOptions.SendTimeout property

Maximum time to wait for outbound transport activity during a single asynchronous send operation.

Applies to transport writes rather than to association-level protocol timers.

Default is InfiniteTimeSpan, which disables the transport-level send timeout.

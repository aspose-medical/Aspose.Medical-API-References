## DicomNetworkServer.StopAsync method

Stops accepting new connections and waits for active associations to finish.

```csharp
public ValueTask StopAsync()
```

### Return Value

A task that completes when the accept loop and tracked associations have stopped.

### Remarks

The server lifecycle is not thread-safe. Calls to [`StartAsync`](../startasync) and `StopAsync` must be serialized and must not overlap. Once shutdown begins, the server completes it deterministically.

## DicomNetworkServer.StartAsync method

Starts the DICOM server and begins listening for inbound DICOM associations.

```csharp
public ValueTask StartAsync(CancellationToken cancellationToken = default)
```

| Parameter | Type | Description |
| --- | --- | --- |
| cancellationToken | CancellationToken | The cancellation token used to abort startup. |

### Return Value

A task that completes when the listener is bound and the accept loop has started.

### Remarks

The server lifecycle is not thread-safe. Calls to `StartAsync` and [`StopAsync`](../stopasync) must be serialized and must not overlap.

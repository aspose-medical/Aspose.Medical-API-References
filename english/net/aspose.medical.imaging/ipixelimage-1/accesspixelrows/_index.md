## AccessPixelRows(PixelRowsAction&lt;TPixel&gt;) {#accesspixelrows}

Provides synchronous access to the image's pixel rows.

```csharp
public void AccessPixelRows(PixelRowsAction<TPixel> action)
```

| Parameter | Type | Description |
| --- | --- | --- |
| action | PixelRowsAction`1 | The callback to invoke with a scoped pixel-row accessor. |

### Remarks

The pixel-row accessor, and any row spans obtained from it, are valid only for the duration of the *action* invocation.

Pixels can be read or replaced through the supplied rows.

The callback is invoked synchronously. Access to the pixel rows is released when the callback returns, including when it terminates by throwing an exception.

### Remarks

The pixel-row accessor, and any row spans obtained from it, are valid only for the duration of the *action* invocation.

The callback is invoked synchronously. Access to the pixel rows is released when the callback returns, including when it terminates by throwing an exception.

This overload allows callers to use a static callback while passing required values explicitly, avoiding the need to capture those values in a closure.

## PixelRowsAction&lt;TPixel,TState&gt; delegate

Represents a callback that receives synchronous access to an image's pixel rows together with application-defined state.

```csharp
public delegate void PixelRowsAction<TPixel, in TState>(PixelRows<TPixel> rows, TState state)
    where TPixel : struct, IPixel<TPixel>, IPixel<TPixel>;
```

| Parameter | Description |
| --- | --- |
| TPixel | The pixel type stored by the image. |
| TState | The type of state passed to the callback. |
| rows | A scoped accessor for the image's pixel rows. |
| state | The application-defined state supplied to the callback. |

### Remarks

When invoked by [`AccessPixelRows`](../ipixelimage-1/accesspixelrows), *rows* and any row spans obtained from it are valid only for the duration of the callback. Pixels can be read or replaced through the supplied rows.

This delegate supports passing required values explicitly to a static callback, avoiding the need to capture those values in a closure.

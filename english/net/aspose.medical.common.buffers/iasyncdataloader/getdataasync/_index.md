## IAsyncDataLoader.GetDataAsync method

Asynchronously resolves the complete byte content identified by *uri*.

```csharp
public ValueTask<Memory<byte>> GetDataAsync(string uri, CancellationToken cancellationToken)
```

| Parameter | Type | Description |
| --- | --- | --- |
| uri | String | The source identifier understood by the loader. |
| cancellationToken | CancellationToken | The token used to cancel the operation. |

### Return Value

A task whose result contains the resolved bytes.

### Remarks

The returned memory may be retained and modified by the consumer. Its backing storage must therefore remain valid for as long as the consumer can access the resolved content.

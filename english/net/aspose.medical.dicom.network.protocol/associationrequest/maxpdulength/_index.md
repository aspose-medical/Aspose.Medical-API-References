## AssociationRequest.MaxPduLength property

The maximum size, in bytes, of a DICOM PDU body that the requestor will accept and advertise. The value represents the UL "Maximum Length Received" item (0x51); `0` means no maximum is specified. The default is `262144` (256 KiB).

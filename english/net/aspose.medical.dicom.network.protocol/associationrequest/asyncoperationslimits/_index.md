## AssociationRequest.AsyncOperationsLimits property

Asynchronous operation limits proposed by the requestor: - the maximum number of asynchronous operations that the requestor may have **invoked** concurrently. - the maximum number of asynchronous operations that the acceptor may have **performed** concurrently. The default value is Synchronous.

```csharp
public AsyncOperationsWindow AsyncOperationsLimits { get; set; }
```

### Remarks

Corresponds to the UL Asynchronous Operations Window negotiation (sub-item 0x53). `0` means unlimited; `1` means synchronous.

## PresentationContextReason enumeration

Outcome of negotiating a DICOM **Presentation Context** during the `A-ASSOCIATE` handshake.

```csharp
public enum PresentationContextReason : byte
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Proposed | `255` | The presentation context has been proposed but not yet accepted or rejected. |
| Accept | `0` | The presentation context was accepted by the acceptor. |
| RejectUser | `1` | The presentation context was rejected by user decision. |
| RejectNoReason | `2` | The presentation context was rejected for an unspecified reason by the provider. |
| RejectSopClassNotSupported | `3` | Rejected because the requested abstract syntax (SOP Class) is not supported. |
| RejectNoCommonTransferSyntax | `4` | Rejected because none of the proposed transfer syntaxes are supported. |

### Remarks

These values correspond to the single-byte `Result/Reason` field carried in each Presentation Context item of the `A-ASSOCIATE-AC` PDU (DICOM PS 3.8, UL protocol). The library-specific value Proposed is used as an in-memory sentinel before a context is accepted or rejected and is not transmitted on the wire.

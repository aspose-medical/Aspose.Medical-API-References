## DeserializeAsyncEnumerable(Stream, DicomXmlSerializerOptions?, CancellationToken) {#deserializeasyncenumerable_1}

Asynchronously deserializes consecutive Native DICOM Model XML fragments from a stream.

```csharp
public static IAsyncEnumerable<Dataset> DeserializeAsyncEnumerable(Stream stream, 
    DicomXmlSerializerOptions? options = null, CancellationToken cancellationToken = default)
```

| Parameter | Type | Description |
| --- | --- | --- |
| stream | Stream | The stream containing the XML fragments. The stream remains open. |
| options | DicomXmlSerializerOptions | Options that select the loader used to resolve Bulk Data references. |
| cancellationToken | CancellationToken | The token used to cancel XML reading or Bulk Data loading. |

### Return Value

An asynchronous sequence that yields one DICOM dataset for each XML fragment, in input order.

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | *stream* is `null`. |
| OperationCanceledException | *cancellationToken* is canceled. |
| XmlException | The input is malformed or contains an invalid Native DICOM Model element. |

### Remarks

An empty or whitespace-only stream produces an empty sequence.

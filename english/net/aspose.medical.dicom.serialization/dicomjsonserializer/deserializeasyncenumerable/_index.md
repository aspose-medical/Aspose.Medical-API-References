## DeserializeAsyncEnumerable(Stream, DicomJsonSerializerOptions?, CancellationToken) {#deserializeasyncenumerable_1}

Asynchronously reads datasets from a DICOM JSON array in a UTF-8 stream.

```csharp
public static IAsyncEnumerable<Dataset?> DeserializeAsyncEnumerable(Stream utf8Json, 
    DicomJsonSerializerOptions? dicomJsonOptions = null, 
    CancellationToken cancellationToken = default)
```

| Parameter | Type | Description |
| --- | --- | --- |

| dicomJsonOptions | DicomJsonSerializerOptions | Options controlling DICOM JSON materialization. |
| cancellationToken | CancellationToken | A token used to cancel reading, enumeration, or asynchronous Bulk Data loading. |

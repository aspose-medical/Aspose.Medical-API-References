## ServiceClassRole enumeration

Defines the DICOM Service Class roles that an Application Entity can assume during association negotiation. This is a flags enum, so multiple roles can be combined.

```csharp
[Flags]
public enum ServiceClassRole : byte
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | `0` | No explicit SCP/SCU Role Selection was negotiated. |
| User | `1` | The Service Class User (SCU) role. An AE acting as an SCU initiates DIMSE requests (e.g. C-STORE, C-FIND). |
| Provider | `2` | The Service Class Provider (SCP) role. An AE acting as an SCP responds to incoming DIMSE requests. |

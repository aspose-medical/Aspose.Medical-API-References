### Remarks

Use this collection through [`AssociationNegotiationOptions`](../associationnegotiationoptions) to describe the presentation contexts that a requestor proposes or an acceptor supports. **A context role is expressed from the local Application Entity perspective**.

Client proposals use the client role directly, because SCP/SCU Role Selection items in an A-ASSOCIATE-RQ describe the association requestor.

Server capabilities use the server role and are translated to the requestor perspective during negotiation: local Provider accepts requestor User, and local User accepts requestor Provider. After negotiation, presentation contexts are matched by message direction. A requestor sends as User and receives as Provider; an acceptor sends as Provider and receives as User.

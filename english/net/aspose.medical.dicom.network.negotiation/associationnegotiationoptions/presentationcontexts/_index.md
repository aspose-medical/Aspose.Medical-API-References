## AssociationNegotiationOptions.PresentationContexts property

The presentation contexts configured for association negotiation.

```csharp
public PresentationContexts PresentationContexts { get; set; }
```

### Remarks

Presentation contexts are configured on association negotiation options rather than on the network client or server builder. The role of each context describes the local Application Entity role: a requestor configures the role it proposes for itself, and an acceptor configures the server capability it supports locally. A `null` role uses the DICOM default roles.

## AssociationTimeoutOptions.CloseTimeout property

Timeout waiting for transport close indication after a local association shutdown action such as A-ASSOCIATE-RJ, A-RELEASE-RP, or A-ABORT.

This is the association-level close-wait timeout used after the protocol shutdown message has been sent and the implementation is waiting for the transport connection to close.

```csharp
public TimeSpan CloseTimeout { get; set; }
```

### Remarks

The default value is `10 seconds`.

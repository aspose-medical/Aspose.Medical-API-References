## UserIdentityTypes enumeration

Specifies the user identity mechanism used in the `User Identity Negotiation` sub-item of an A-ASSOCIATE exchange (DICOM PS3.7, §D.3.3.7).

```csharp
public enum UserIdentityTypes
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Username | `1` | Username only. |
| UsernameAndPasscode | `2` | Username plus passcode (password or similar secret). |
| Kerberos | `3` | Kerberos service ticket. |
| Saml | `4` | SAML assertion. |
| Jwt | `5` | JSON Web Token (JWT). |

### Remarks

The selected value determines the content of the sub-item's variable-length. All length fields in the sub-item are big-endian (network byte order). For non-Kerberos types, transport security (e.g., TLS) is typically required if confidentiality of the credential is desired.

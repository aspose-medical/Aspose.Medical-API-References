## CMoveOptions enumeration

Defines the C-MOVE extended negotiation options supported by an Application Entity (AE). These flags indicate additional retrieval capabilities negotiated during association setup.

```csharp
[Flags]
public enum CMoveOptions
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | `0` | No extended negotiation options are requested or supported. |
| RelationalRetrieval | `2` | Indicates support for relational retrieval, allowing hierarchical retrieval relationships (e.g., STUDY→SERIES→IMAGE) to be specified in a single C-MOVE request. |
| EnhancedMultiFrameImageConversion | `4` | Indicates support for enhanced multi-frame image conversion during C-MOVE operations, enabling multi-frame images to be converted to single-frame references if required. |

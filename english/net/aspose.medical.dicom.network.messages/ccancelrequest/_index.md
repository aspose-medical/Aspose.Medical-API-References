### Remarks

C-CANCEL allows a Service Class User to request the cancellation of a pending operation. This message does not have a corresponding response (uses [`NoneDicomNetworkResponse`](../nonedicomnetworkresponse)). C-CANCEL Protocol/Structure: https://dicom.nema.org/medical/dicom/current/output/html/part07.html#sect_9.3.2.3.

### Remarks

A C-ECHO response is typically used to test and verify a successful association between DICOM peers. It doesn't transmit any medical imaging data; instead, it checks if the server is alive and responsive. C-ECHO Protocol/Structure: https://dicom.nema.org/medical/dicom/current/output/chtml/part07/sect_9.3.5.2.html

## CGetOptions enumeration

Defines the extended negotiation options for the C-GET SOP Class, used to communicate additional retrieval capabilities supported by an Application Entity (AE).

```csharp
[Flags]
public enum CGetOptions
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | `0` | No extended negotiation options are requested or supported. |
| RelationalRetrieval | `2` | Indicates support for relational retrieval, allowing hierarchical relationships (e.g., STUDY → SERIES → IMAGE) to be traversed and retrieved in a single C-GET operation. |
| EnhancedMultiFrameImageConversion | `4` | Indicates support for enhanced multi-frame image conversion, enabling multi-frame images to be retrieved as converted single-frame instances when necessary. |

## CFindOptions enumeration

Specifies the C-FIND extended negotiation options supported by an Application Entity (AE). These flags indicate additional query capabilities negotiated during association setup.

```csharp
[Flags]
public enum CFindOptions
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | `0` | No extended negotiation options are requested or supported. |
| RelationalQueries | `2` | Indicates support for Relational Queries, allowing hierarchical query relationships (e.g., STUDY→SERIES→IMAGE) to be expressed in a single query. |
| DateTimeMatching | `4` | Indicates support for combined Date and Time matching within query attributes. |
| FuzzySemanticMatching | `8` | Indicates support for Fuzzy Semantic Matching of Person Names, enabling approximate or phonetic name comparisons. |
| TimezoneQueryAdjustment | `10` | Indicates support for Timezone Query Adjustment, allowing interpretation of date/time values relative to a specified time zone offset. |
| EnhancedMultiFrameImageConversion | `20` | Indicates support for Enhanced Multi-Frame Image Conversion during C-FIND operations, enabling multi-frame image references to be converted to single-frame references if needed. |
